# LazyPC — Client

## Назначение

Клиент:

* отображает видеопоток
* отправляет **сырые события ввода** (тач, scroll, клавиатура)

Клиент **не интерпретирует ввод**.

---

## Ключевой принцип

> Клиент — датчик

* нет логики кликов
* нет жестов
* нет таймингов
* нет знания раскладки

---

## Экран

### ScreenSurfaceView

* весь экран = тачпад
* чёрные полосы активны
* scroll-зона поддерживается

---

## PointerProcessor

Функции:

* принимает MotionEvent
* считает относительное dx / dy
* определяет количество пальцев

Не делает:

* клики
* удержания
* scroll-интерпретацию

---

## ScrollProcessor

* фиксирует 2 пальца
* вычисляет scroll dx / dy
* отправляет PACKET_RAW_SCROLL

---

## KeyboardProcessor

* принимает Android KeyEvent
* преобразует в Linux keycode
* отправляет PACKET_RAW_KEY

Клиент:

* не знает язык
* не знает modifiers
* не знает состояния

---

## MouseEmitter / KeyEmitter

* формируют строгие пакеты
* проверяют размер payload
* отправляют по WebSocket

---

## WebSocket

* один канал для видео и ввода
* reconnect безопасен
* сервер восстанавливает состояние

---

## Совместимость

Такой клиент может быть:

* Android
* iOS
* Desktop
* Web
* Steam Deck

Серверу всё равно — формат един.

---

## Зафиксированное состояние

* Видео стабильно
* Pointer стабилен
* Scroll стабилен
* Keyboard стабилен
* Нет логики на клиенте
